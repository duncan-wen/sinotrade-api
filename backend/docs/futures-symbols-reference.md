## ⚠️ 注意事項

### 🔄 自動映射

- 系統會將 `CDFJ5` 自動映射為 `CDFR1`
- 建議直接使用標準化格式 `*R1/*R2`

### 📅 合約轉換

- 近月合約 (R1) 流動性較好,適合短期交易
- 次月合約 (R2) 適合較長期的投資策略

### 💾 數據連續性

- 使用標準化代碼可確保歷史數據的連續性
- 避免因合約轉換造成的數據斷層

## 🆕 新增期貨商品

當台灣期貨交易所推出新的期貨商品時:

1. **自動支援**:系統會自動支援新的 `*R1/*R2` 格式
2. **API 更新**:不需要修改 API 代碼
3. **前端更新**:可在前端下拉選單中新增選項

### 範例:新增期貨商品

```javascript
// 假設新推出 XYZ 期貨,直接使用即可
klineSocketIOService.subscribe("XYZR1"); // 近月
klineSocketIOService.subscribe("XYZR2"); // 次月
```
